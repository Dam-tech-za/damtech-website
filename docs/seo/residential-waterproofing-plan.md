# Residential waterproofing plan

The search-intent research, architecture decision and page list live in `docs/residential-waterproofing-seo-plan.md` (Cowork, 17 Oct 2026, built on first-party Search Console data). It was reviewed and kept; this file records what the takeover verified and changed.

## Architecture (unchanged URLs)
| URL | Role | Verified |
|---|---|---|
| `/waterproofing/` | Residential hub (keeps the equity of the old `/bitumen-waterproofing/` 301) | Distinct hub copy; Betty's Bay already ranks #1 for "waterproofing company betty's bay" per the Cowork GSC export |
| `/roof-waterproofing/` | Roofs, flat slabs, parapets, leak repair | Explains torch-on vs liquid-applied by substrate; says when it's roofing repair, not waterproofing |
| `/foundation-waterproofing/` | Foundations, retaining walls, damp-proofing | Separates rising damp from roof leaks; no one-system-fits-all claims |
| `/torch-on-waterproofing/`, `/waterproofing-membranes-and-coatings/` | Method/material guides | Technical, comparison table, no product-brand claims |
| `/waterproofing-pretoria/` | Pretoria / Centurion / Tshwane | Distinct local content, no invented address |
| `/waterproofing-overstrand/` | Betty's Bay → Gansbaai | States "not a Cape Town suburb"; base is a service area, not a walk-in office |

No new location pages were added — the two regional pages are genuinely different and further town pages would be doorway pages without local proof (photos, case studies).

## What the takeover changed
- Presentation: blue colour-block hero with an enquiry card (areas served, call, WhatsApp photos, quote form) instead of a plain dark banner; editorial content rows; dark process band; ink CTA. All headings and copy unchanged (SEO diff clean).
- Lead flow: every residential CTA pre-selects the real `Roof / home waterproofing` service; first-touch landing page is stored and is now readable in the admin "Enquiry source" panel with a Pretoria/Overstrand region hint.
